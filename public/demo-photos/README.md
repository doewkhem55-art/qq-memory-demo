# Demo Photos

这里用于放置「QQ 时光回廊」Demo 的本地图片素材。

当前可以使用本地安全占位素材，后续可替换为 AI 生成图片、版权安全图片或脱敏后的演示素材。请避免使用真实陌生人清晰正脸、学校 logo、商业商标和隐私照片。

图片放入后，只需要在 `mockData.js` 或 `aiMemoryService.js` 的 `photoAssets.src` 中引用 `/demo-photos/...` 路径即可。当前 Demo 不从外部网络加载图片。

目录说明：

- `graduation/`：高中毕业季、告别、操场与聚餐
- `campus/`：大学开学、校园日常、宿舍与操场
- `military-training/`：军训、队列、训练场
- `family-travel/`：家人旅行、节假日、出行
- `friends/`：朋友、同学、留言与互动
- `self/`：关于我自己、独处日常、成长片段
- `recent/`：持续归档、近期照片、新相册
- `emotion/`：开心、告别、成长变化等情绪主题
- `appearance/`：发色、穿搭、形象变化
- `relationship/`：家人、朋友、同学等关系分类
