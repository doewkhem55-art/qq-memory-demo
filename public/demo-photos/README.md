# Demo Photos

这里用于放置「QQ 时光回廊」Demo 的本地安全演示素材。

当前素材用于展示 QQ 时光回廊的青春相册气质：毕业、校园、军训、旅行、朋友聚会、家人、独处日常、形象变化和人物关系等记忆场景。

当前主展示素材为本地 JPG 真实感 Demo 照片，部分来自 AI 生成，部分由本地程序生成手机相册风格照片。SVG 插画素材仍保留为加载失败时的 fallback，不作为默认主展示内容。

安全约束：

- 不使用真实陌生人清晰正脸。
- 不使用学校 logo。
- 不使用商业商标或品牌标识。
- 不使用隐私照片。
- 不使用地图、图表、论文、数据可视化等工具测试图作为默认展示素材。
- 当前 Demo 不会从外部网络加载图片。

后续正式上线时，可将这些演示素材替换为用户授权后的真实 QQ 空间相册资源，或替换为经过版权与隐私审核的正式展示素材。

图片放入后，通过 `src/data/photoAssets.js` 引用 `/demo-photos/...` 路径即可。当前读取优先级为：用户上传图片、本地 JPG/PNG/WebP 真实感 Demo 图片、SVG fallback、最终渐变兜底。

目录说明：

- `graduation/`：高中毕业季、告别、操场与聚餐
- `campus/`：大学开学、校园日常、宿舍与操场
- `military-training/`：军训、队列、训练场
- `family-travel/`：家人旅行、节假日、出行
- `friends/`：朋友、同学、留言与互动
- `self/`：关于我自己、独处日常、成长片段
- `recent/`：持续归档、近期照片、新相册
- `emotion/`：开心、告别、成长变化等情绪主题
- `appearance/`：发色、穿搭、形象变化
- `relationship/`：家人、朋友、同学等关系分类
